# Components

Generated by `pocket gen` from `engine/*/meta/*.toml`. Every component is a plain record; `world.set(entity, name, partial)` merges the given fields onto the current value (or the default when the component is new).

## Transform

Position, rotation and scale relative to the parent entity (or the world when there is no parent).

| Field | Type | Default | Meaning |
|---|---|---|---|
| `position` | vec3 | [0.0, 0.0, 0.0] | Local position in meters. |
| `rotation` | quat | [0.0, 0.0, 0.0, 1.0] | Local rotation as a unit quaternion (x, y, z, w). |
| `scale` | vec3 | [1.0, 1.0, 1.0] | Local scale. |

## WorldTransform

World-space transform computed from the Transform hierarchy every tick. Read only. Derived: computed by the engine, not stored in scenes.

| Field | Type | Default | Meaning |
|---|---|---|---|
| `position` | vec3 | [0.0, 0.0, 0.0] | World position. |
| `rotation` | quat | [0.0, 0.0, 0.0, 1.0] | World rotation. |
| `scale` | vec3 | [1.0, 1.0, 1.0] | World scale. |

## Velocity

Linear and angular velocity. The built-in motion system integrates Transform from it every tick.

| Field | Type | Default | Meaning |
|---|---|---|---|
| `linear` | vec3 | [0.0, 0.0, 0.0] | Meters per second, in the parent's space. |
| `angular` | vec3 | [0.0, 0.0, 0.0] | Radians per second around local X, Y, Z. |

## Health

Hit points. Gameplay decides what zero means; the engine only stores and reports it.

| Field | Type | Default | Meaning |
|---|---|---|---|
| `current` | f32 | 100.0 | Current hit points. |
| `max` | f32 | 100.0 | Maximum hit points. |

## Lifetime

Seconds remaining before the entity is destroyed by the lifetime system.

| Field | Type | Default | Meaning |
|---|---|---|---|
| `seconds` | f32 | 1.0 | Remaining seconds; the entity is destroyed when it reaches zero. |

## Camera

Perspective camera. The renderer uses the first active camera.

| Field | Type | Default | Meaning |
|---|---|---|---|
| `fov_degrees` | f32 | 60.0 | Vertical field of view in degrees. |
| `near` | f32 | 0.1 | Near clip distance. |
| `far` | f32 | 1000.0 | Far clip distance. |
| `active` | bool | true | Whether this camera renders. |

## Light

A light source. kind 0 = directional (shines along -Z of the entity), 1 = point.

| Field | Type | Default | Meaning |
|---|---|---|---|
| `kind` | i32 | 0 | 0 directional, 1 point. |
| `color` | color | [1.0, 1.0, 1.0, 1.0] | Linear RGB color; alpha unused. |
| `intensity` | f32 | 1.0 | Multiplier applied to color. |
| `range` | f32 | 10.0 | Point light range in meters. |

## MeshRenderer

Draws a built-in primitive mesh with a flat material.

| Field | Type | Default | Meaning |
|---|---|---|---|
| `mesh` | i32 | 0 | 0 cube, 1 sphere, 2 plane, 3 cylinder. |
| `color` | color | [0.8, 0.8, 0.8, 1.0] | Base color, linear RGB. |
| `visible` | bool | true | Whether the mesh is drawn. |

## Bounds

Axis-aligned bounding box in world space, computed by the engine from the mesh and WorldTransform. Read only. Derived: computed by the engine, not stored in scenes.

| Field | Type | Default | Meaning |
|---|---|---|---|
| `min` | vec3 | [0.0, 0.0, 0.0] | Minimum corner. |
| `max` | vec3 | [0.0, 0.0, 0.0] | Maximum corner. |
