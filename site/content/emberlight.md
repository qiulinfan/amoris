# Emberlight

[Play](../../play/emberlight/) · [Prompt](emberlight-prompt.txt) ·
[Source](https://github.com/qiulinfan/amoris/tree/main/samples/emberlight)

Turn mirrors and a prism to light five lanterns across four observatory chambers.
WASD walks, the mouse looks, left click turns the nearest mirror, right click resets the room.
Drag to look when the browser cannot lock the mouse. Desktop WebGPU, keyboard and mouse.
The native playthrough has a soundtrack; browser audio is not available.

| Harness | Model | Initial time | Tokens |
|---|---|---|---|
| DeepSeek Harness | DeepSeek Flash | ~100 min | 173.7M total, including 172.4M cached input |

The figures describe the original autonomous session on 26 October 2026: 421 model steps.
Time is the approximate span of the original run log; tokens sum its per-step usage, including
cached input. The playable edition includes follow-up visual fixes and browser integration.

The homepage video is a scripted API playthrough captured in the native engine. Its soundtrack
uses the game's generated audio, mixed at the recorded event times. It is not a development film
or a model decision-loop benchmark.
