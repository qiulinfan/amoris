# Windward — The Wind Road

[Play](../../play/windward/) · [Prompt](wind-road-prompt.txt) ·
[Source](https://github.com/qiulinfan/amoris/tree/main/samples/windward)

Fly a glider through ten wind gates between floating islands.
A / D bank, W / S dive and climb, Shift gust, Space burst, right click restart. Escape opens the
pause veil; drag to look when the browser cannot lock the mouse. Desktop WebGPU, keyboard and
mouse. Browser audio is not available.

| Harness | Model | Initial time | Tokens |
|---|---|---|---|
| DeepSeek Harness | DeepSeek Flash | ~88 min | 139.4M total, including 138.7M cached input |

The figures describe the original autonomous session on 26 October 2026: 356 model steps.
Time is the approximate span of the original run log; tokens sum its per-step usage, including
cached input. The playable edition includes follow-up polish and browser integration.

The homepage video is a scripted API playthrough in the native engine, not a development film or
a model decision-loop benchmark. It is sampled from simulation ticks, so its encoded frame rate
does not measure runtime performance.
