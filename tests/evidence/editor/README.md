# Editor evidence (2026-09-18)

- `editor-ui-sample.png`: `pocket editor ui -- --frames 90 --capture ...` in a window (1920x1080 pixels for a 960x540 point window). Toolbar, hierarchy, the scene pane hosting the sample's own HUD, the schema-driven inspector, and the console showing the runtime log.
- `assets-tab.png`: the sprites sample opened headless (1024 by 640) with the Assets tab clicked over the control server (`ui.query {name: "tab:assets"}`, `ui.click`, `capture`): every file under `assets/` by kind and size, the images with a thumbnail drawn by the interface's `image` style (the coin and player sheets as wide strips, the sky as a tall column, each fitted inside a 16 by 16 box), and the hint that a click describes a file and a drag onto the scene places it.
- `script-tab.png`: the sprites sample opened headless (1024 by 640) with the Script tab clicked and `scripts/main.tsx` opened over the control server (`ui.click` on `tab:script` and on `script:scripts/main.tsx`, `capture`): the project's scripts listed on the left, the file in the text area coloured as TypeScript (calls blue, strings green, keywords purple, numbers orange, types yellow; the area's `syntax` is the file's path, so `ui.describe` reports `ts`) and scrolled to its end, where the caret was put, and the header with the file name, Save and the note that Cmd/Ctrl+Return saves. Retaken 2026-09-29 for syntax colouring.
- `blender-place.png`: a Blender file placed from the editor (2026-09-29). `make-suzanne.py` (run by Blender 4.5: `Blender -b --factory-startup --python make-suzanne.py -- suzanne.blend`) makes a stone plinth with a bevel, a gold Suzanne subdivided and smoothed on it, a warm point lamp and a camera, saved as `.blend`; copied into the physics sample's `assets/`, the editor opened headless (1280 by 800), the Assets tab clicked, the file picked (the line above the list: 10173 vertices, 15932 triangles, 2 submeshes, 1 light, 1 camera, read through Blender and kept as `.imported/assets/suzanne.blend.glb`; the row says `via Blender`) and Place clicked: the file came in as its node tree in the middle of the pane (the notice: `as its node tree with 1 light and 1 camera`), the lamp lighting the plinth warm from the left, the camera inactive, the root selected with its gizmo. The file and its conversion were removed afterwards.
- `showcase-editor.png` (2026-09-29): `samples/showcase` opened in the editor headless (1280 by 800) before Play: the courtyard in the scene pane with every renderer feature of the sample on (sky, cascades, volumetric fog, the pool's reflections, lanterns with shadows, AgX, bloom, AO, TAA), the hierarchy of its 51 entities.
- `mixer.png` (2026-09-29): `samples/audio` in the editor with the Audio tab open after a click on the ambience bus's slider (80 percent): the master, the project's ambience bus with its hum and its ducking under `fx`, and the main bus; Save mixer wrote `audio.json` (removed afterwards).
- `session.md`: a headless editor session with `samples/physics`, driven only through commands an agent has: `ui.snapshot` of the editor, click on the `entity:Ramp` row, the inspector's `Transform.position.x` input edited by `ui.click` / `ui.key` / `ui.type` and committed with Return (`world.get` shows the value), Play (the project's scripts start and drop crates), Pause, three Steps, the Transcript tab, Stop (the scene comes back with the edit kept; the crates are gone).
- `editor-physics-headless.png`: the capture taken at the end of that session.
